# Service images

Drop the official Reesh service images here with these exact filenames — the
site reads them from `lib/content.js` (`subBrands[].image`) and the portfolio.

| File | Sub-brand | Shows | Aspect |
|---|---|---|---|
| `reesh_designs.jpeg` | Reesh Design | Feather logo on a lit podium with creative icons | 3:2 |
| `reesh_digital.jpeg` | Reesh Digital | Brand-identity mockup set (billboard, bag, cup, apparel, cards) | 3:2 |
| `reesh_Media.jpeg` | Reesh Media | REESH video-production crew filming | 3:2 |
| `reesh_Print.jpeg` | Reesh Print | Branded print/stationery mockup set | 16:9 |

Reesh Web has no official image yet — it uses a temporary device/website mockup
(flagged `// TODO: awaiting official Reesh Web image` in `content.js`).

Filenames are case-sensitive and authoritative — match them exactly.
